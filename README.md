# 💎 Jewelry E-Commerce Website

A modern and responsive jewelry e-commerce website built with **React and Vite**. The project provides a clean shopping experience where users can browse jewelry products, add products to their cart, manage quantities, and view the total price.

## ✨ Features

* 🏠 Modern homepage with hero section
* 💍 Jewelry product collection
* 🖼️ Product images and detailed product cards
* 🛒 Add products to cart
* ➕ Increase product quantity
* ➖ Decrease product quantity
* 🗑️ Remove products from cart
* 💰 Automatic cart total calculation
* 📱 Responsive design
* 🧩 Reusable React components
* ⚡ Fast development with Vite
* 🎨 Clean and minimal user interface

## 🛠️ Technologies Used

* **React**
* **Vite**
* **JavaScript**
* **HTML5**
* **CSS3**
* **React Router**
* **React Context API**

## 🛒 Shopping Cart

The project uses React's **Context API** to manage cart state across components.

Users can:

1. Add jewelry products to the cart.
2. Increase or decrease quantities.
3. Remove products.
4. View the updated cart total.

## 📱 Responsive Design

The website is designed to provide a smooth experience across different screen sizes, including desktop, tablet, and mobile devices.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/eshaeman59/Jewelry-E-Commerce.git
```

Move into the project folder:

```bash
cd Jewelry-E-Commerce
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL provided by Vite in your browser.
